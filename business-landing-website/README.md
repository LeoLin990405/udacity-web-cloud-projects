# Business Landing Website

This project is a static two-page business website for Cedar & Bloom Workspace Design.

## Pages

- `index.html` is the home page.
- `contact/contact.html` is the secondary page with a contact form.

## Structure

- `css/global.css` contains shared typography, navigation, buttons, and footer styles.
- `css/home.css` contains home-page layout and component styles.
- `css/contact.css` contains contact-page layout and form styles.
- `images/studio-workspace.jpg` is the local image asset used by the hero and figure.

## Rubric Coverage

The site uses semantic HTML landmarks, a navbar and footer on every page, a hero section, repeated cards, an image with a caption and alt text, labeled form fields, Flexbox, CSS Grid, and responsive media queries for mobile and tablet layouts.
